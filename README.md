# 📊 Customer Churn Analysis

An end-to-end **Data Analytics project** focused on analyzing customer churn, customer retention, revenue, subscription patterns, contract types, payment methods, and customer behavior.

This project demonstrates a complete data analytics workflow starting from raw and unclean Excel data, followed by data cleaning and feature engineering using Python, database integration with MySQL, SQL-based analysis, and finally an interactive Power BI dashboard.

---

## 📌 Project Overview

Customer churn is an important business problem because understanding why customers leave can help organizations improve customer retention and make better business decisions.

In this project, an unclean customer dataset was transformed into a structured and analysis-ready dataset. Python was used for data cleaning and feature engineering, MySQL was used to store the cleaned data, SQL was used to perform analytical queries, and Power BI was used to create an interactive dashboard.
